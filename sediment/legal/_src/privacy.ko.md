## 1. 수집하는 개인정보

회사는 서비스 제공을 위해 아래의 개인정보를 수집·처리합니다.

### 1-1. 익명 가입 시
- **자동 생성 식별자**: Firebase Authentication UID (이메일·이름 없음)
- **단말 정보**: 운영체제 종류, 시간대(timezone), 언어 설정(locale)
- **Firebase Installation ID**: 앱 설치마다 부여되는 비식별 식별자 (광고 ID 아님)
- **사용 통계**: 화면 전환, 버튼 탭, 세션 길이 등 비식별 이용 이벤트 (Firebase Analytics)

### 1-2. 정식 계정 연결 시 (이메일·Apple·Google)
- **이메일 주소** (필수)
- **표시 이름**, **프로필 사진 URL** (Apple/Google 제공 시 자동 수집)

### 1-3. 서비스 이용 중 생성·저장되는 정보
- **이용자가 작성한 기록(deposit)**: 텍스트, 첨부 사진
- **AI 요약 결과(layer)**: 텍스트, AI 호출 메타데이터
- **사용 통계**: 작성 시각·연속 작성일·크레딧 잔액 변동 내역

### 1-4. 결제 시
- **구독 상태**: 활성 여부, 만료 시각, 상품 ID, 결제 수단 종류 (App Store / Google Play)
- 회사는 **카드 번호·계좌 번호 등 결제 수단 정보 자체를 직접 수집·저장하지 않습니다.** 해당 정보는 Apple, Google 및 RevenueCat 이 처리합니다.

회사는 이용자가 자발적으로 입력한 정보 외에는 별도의 추적·광고 식별자를 수집하지 않으며, 쿠키·픽셀·App Tracking Transparency 추적 권한을 사용하지 않습니다. Firebase Analytics 가 수집하는 사용 통계는 익명화된 형태이며, Apple App Tracking Transparency 가 정의한 '추적'(다른 회사 앱·웹 데이터와 결합한 광고 타겟팅)에 해당하지 않습니다.

## 2. 수집·이용 목적

| 항목 | 목적 |
|---|---|
| Firebase UID | 이용자 식별, 자료 분리 |
| 이메일·표시 이름 | 계정 복구, 다른 기기에서의 동기화 |
| 시간대·언어 설정 | UI/AI 출력 현지화, 작성 시각의 정확한 기록 |
| 기록·사진 | 서비스의 핵심 기능(저널링·AI 요약) 제공 |
| AI 호출 메타데이터 | 사용량 집계, 크레딧 차감, 오류 진단 |
| 구독 상태 | 결제 권한 확인, 계정 삭제 시 활성 구독 차단 |
| Firebase Installation ID·사용 통계 | 사용 패턴 분석을 통한 서비스 개선 (광고 X) |

회사는 위 목적 외의 용도로 개인정보를 이용하지 않으며, 이용 목적이 변경될 경우 별도의 동의를 받습니다.

## 3. 보유 및 이용 기간

- **계정 활성 기간 동안** 보유합니다.
- 이용자가 앱 내 "계정 영구 삭제" 기능을 사용하면 **즉시** 다음을 모두 삭제합니다:
  - Firebase Authentication 사용자
  - Firestore 의 이용자 문서·기록·사진 메타·AI 요약·크레딧 거래 내역
  - Firebase Cloud Storage 의 첨부 사진·음성 파일
  - 활성 구독이 있을 경우 계정 삭제는 차단되며, 이용자는 먼저 App Store/Google Play 에서 구독을 취소해야 합니다.
- **법령상 보존 의무**가 있는 경우(예: 「전자상거래법」상 결제 기록 5년)에는 해당 기간 동안 분리 보관 후 파기합니다.
