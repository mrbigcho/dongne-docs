# Sediment プライバシーポリシー

**施行日**: {{EFFECTIVE_DATE}}
**最終更新日**: {{LAST_UPDATED}}

{{COMPANY_NAME}}(以下「当社」)は、モバイルアプリケーション「Sediment」(以下「本サービス」)を通じて取得する利用者の個人情報を、以下のとおり取り扱います。本ポリシーは、日本の「個人情報の保護に関する法律」(個人情報保護法)その他関連法令を遵守して定めています。

---

## 1. 取得する個人情報

### 1-1. 匿名利用時
- **自動生成識別子**: Firebase Authentication UID(メール・氏名なし)
- **端末情報**: タイムゾーン、言語設定
- **Firebase Installation ID**: アプリのインストールごとに付与される非識別子(広告識別子ではありません)
- **利用イベント**: 画面遷移・タップ・セッション長などの匿名化された利用情報(Firebase Analytics 経由)

### 1-2. アカウント連携時(メール・Apple・Google)
- **メールアドレス**(必須)
- **表示名**、**プロフィール画像 URL**(Apple・Google が提供する場合)

### 1-3. サービス利用中に作成・保存される情報
- **利用者が記録した内容(かけら)**: テキスト、添付写真
- **AI レイヤー**: AI が生成した要約および呼び出しメタデータ
- **利用統計**: 作成時刻、連続記録日数、クレジット残高変動

### 1-4. 決済時
- **サブスクリプション状態**: 有効フラグ、満了日時、商品 ID、決済元(App Store / Google Play)
- 当社は**カード番号や口座番号などの決済手段情報を直接取得・保管しません。** これらの情報は Apple、Google、RevenueCat が処理します。

当社は、利用者が自発的に入力した情報以外、Cookie・広告識別子・第三者トラッカー・App Tracking Transparency による追跡を行いません。Firebase Analytics が収集する利用イベントは匿名化されており、Apple App Tracking Transparency が定義する「追跡」(他社アプリ・ウェブサイトのデータと結合した広告ターゲティング)には該当しません。

## 2. 利用目的

| 取得項目 | 利用目的 |
|---|---|
| Firebase UID | 利用者の識別、データ分離 |
| メールアドレス・表示名 | アカウント復旧、別端末からの同期 |
| タイムゾーン・言語設定 | UI / AI 出力の現地化、正確な時刻記録 |
| かけら・写真 | サービスの中核機能(ジャーナリング・AI レイヤー)の提供 |
| AI 呼び出しメタデータ | 利用量集計、クレジット計算、障害診断 |
| サブスクリプション状態 | 権利確認、有効なサブスク中のアカウント削除ブロック |
| Firebase Installation ID・利用イベント | 匿名化された利用分析によるサービス改善(広告利用なし) |

これらの目的を超えて利用する場合は、事前に同意を取得します。

## 3. 保有期間

- アカウントが有効な間、保有します。
- アプリ内の「アカウント完全削除」を実行すると、**直ちに**以下を削除します:
  - Firebase Authentication 利用者
  - Firestore のすべての利用者ドキュメント、かけら、写真メタデータ、AI レイヤー、クレジット履歴
  - Storage 内の添付写真・音声ファイル
- 有効なサブスクリプションがある場合、削除はブロックされ、利用者は先に App Store / Google Play でサブスクをキャンセルする必要があります。
- 法令上の保存義務がある情報(例: 特定商取引法に基づく取引記録)は、所定の期間のみ分離保管した上で廃棄します。

| 移転先 | 移転先国 | 移転日時 | 移転項目 | 利用目的 | 保有期間 |
|---|---|---|---|---|---|
| Google LLC (Firebase) | 米国 | 加入・利用時の常時 | 第1条記載の全項目 | データベース・認証・保管 | アカウント削除まで |
| Google LLC (Gemini API) | 米国 | AI レイヤー生成時 | 利用者のテキスト | AI 要約 | API 呼び出し後保持しない |

## 7. 安全管理措置

当社は以下の技術的・組織的安全管理措置を実施します:
- すべての通信を TLS 1.2 以上で暗号化
- Firebase App Check による未認可クライアントの遮断
- Firestore Security Rules による本人データのみのアクセス制限
- 認証トークンの端末セキュアストレージ保管
- パスワードは Firebase Authentication 側で一方向ハッシュ保存(当社は平文を保有しません)
