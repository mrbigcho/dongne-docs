본 페이지는 Final Whistle 계정과 관련 데이터를 삭제하는 방법을 안내합니다. 앱 설치 여부와 관계없이 누구든 삭제를 요청할 수 있습니다.

1. 앱 내에서 직접 삭제 (권장)

가장 빠른 방법은 앱에서 직접 삭제하는 것입니다.

  • Final Whistle 앱 또는 웹 실행
  • 우측 하단 MY 탭으로 이동
  • 화면 하단 계정 삭제 영역 까지 스크롤
  • 계정 삭제 버튼 누름
  • 확인 다이얼로그에서 한 번 더 확인

처리는 즉시 시작되며, 늦어도 30일 이내에 모든 데이터가 영구 삭제됩니다.

2. 이메일로 삭제 요청

앱을 사용할 수 없거나 사용하고 싶지 않은 경우(예: 이미 앱을 삭제한 경우), 이메일로도 요청할 수 있습니다.

  • 수신: mrbigcho@gmail.com
  • 제목: Final Whistle 계정 삭제 요청
  • 본문: Final Whistle 가입에 사용한 이메일 주소를 알려주세요. Apple/Google 로그인을 쓰셨다면 표시 이름과 기억나는 식별 정보를 함께 적어주시면 본인 확인 후 처리합니다.

요청은 30일 이내 처리되며, 완료 시 확인 메일을 보내드립니다.

3. 삭제 범위

다음 데이터가 영구 삭제됩니다.

  • Firebase Authentication 계정 (UID, 이메일, OAuth 식별자)
  • 백엔드 데이터베이스의 이용자 프로필·설정·알림 토큰
  • 본인이 단독으로 작성·소유한 콘텐츠
  • 본인이 다른 클럽·대회에 작성한 코멘트·메타데이터 (작성자 식별자 익명화 또는 제거)
  • streak·사용 통계·푸시 토큰

4. 삭제되지 않는 데이터

다음은 법적·운영상 이유 또는 다른 참가자와의 공동 이용 사유로 보존됩니다.

  • 공동 이용 중인 클럽·대회 콘텐츠 — 본인이 만든 클럽·대회라도 다른 참가자가 함께 참여 중이면 해당 대회 종료 시까지 유지됩니다. 사전에 본인이 직접 삭제 또는 운영 권한을 양도해 주세요.
  • 공유 스코어보드 링크 — 이미 공개된 매치 결과·순위표는 다른 참가자의 콘텐츠로 남으며 자동 제거되지 않습니다.
  • 익명·집계된 사용 로그 — 개인을 특정할 수 없으며 서비스 개선 목적으로 보관됩니다.
  • 법령상 보존 의무 데이터 — 「전자상거래법」상 거래 기록(5년) 등. 별도 보관되며 법정 보존 기간 종료 시 삭제됩니다(현재 결제 기능은 제공되지 않으므로 해당 사항은 사실상 발생하지 않습니다).

5. 처리 시간

  • 앱 내 삭제: 즉시 시작 → 30일 이내 완료
  • 이메일 요청: 본인 확인 후 30일 이내 완료
  • 처리 진행 중에도 이용자의 데이터는 보안 통제 하에 유지되며, 외부 공유·광고 등 새로운 처리는 즉시 중단됩니다.
