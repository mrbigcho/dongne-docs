{{COMPANY_NAME}}(이하 "회사")는 모바일·웹 애플리케이션 "Final Whistle"(이하 "서비스")을 통해 수집하는 이용자의 개인정보를 다음과 같이 처리합니다. 회사는 「개인정보 보호법」 제30조에 따라 이용자의 개인정보를 보호하고 권익을 보장하기 위해 본 처리방침을 수립·공개합니다.

## 1. 수집하는 개인정보

회사는 서비스 제공을 위해 아래의 개인정보를 수집·처리합니다.

### 1-1. 계정 가입 시 (Apple · Google · 이메일)
- **이메일 주소** (필수)
- **표시 이름**, **프로필 사진 URL** (Apple/Google 제공 시 자동 수집)
- **Firebase Authentication UID** — 자동 생성되는 식별자

### 1-2. 단말 정보 (자동 수집)
- 운영체제 종류·버전, 앱 버전, 기기 모델 (Firebase Crashlytics, Analytics)
- 시간대(timezone), 언어 설정(locale)
- **Firebase Cloud Messaging 토큰** — 푸시 알림 전송용 비식별 식별자
- **사용 통계** — 화면 전환·탭·세션 길이 등 비식별 이용 이벤트 (Firebase Analytics)

### 1-3. 서비스 이용 중 생성·저장되는 정보
- **이용자 생성 콘텐츠** — 클럽 정보, 대회·매치 데이터, 경기 결과·이의 신청·관리자 판정 기록
- **참가 기록** — 가입한 클럽 멤버십, 참가한 대회·매치, 작성한 코멘트
- **공유 링크 접근 로그** — 공유된 스코어보드의 접근 빈도 (집계 형태)

회사는 이용자가 자발적으로 입력한 정보 외에는 별도의 추적·광고 식별자를 수집하지 않으며, 쿠키·픽셀·App Tracking Transparency 추적 권한을 사용하지 않습니다. Firebase Analytics 가 수집하는 사용 통계는 익명화된 형태이며, Apple App Tracking Transparency 가 정의한 '추적'(다른 회사 앱·웹 데이터와 결합한 광고 타겟팅)에 해당하지 않습니다.

회사는 다음 정보를 **수집하지 않습니다**: 정확한 위치, 건강·의료 정보, 금융 계좌 번호, 주소록, 별도 업로드 외의 사진·영상, 광고 식별자(IDFA·AAID).

## 2. 수집·이용 목적

| 항목 | 목적 |
|---|---|
| Firebase UID | 이용자 식별, 자료 분리 |
| 이메일·표시 이름 | 계정 복구, 다른 기기에서의 동기화 |
| 프로필 사진 | 대회·매치·순위표 등에서의 본인 표시 |
| 시간대·언어 설정 | UI 현지화, 매치 시각의 정확한 기록 |
| 이용자 콘텐츠 (클럽·대회·결과) | 서비스의 핵심 기능 제공 |
| FCM 토큰 | 본인 차례·결과 등록 등 푸시 알림 발송 |
| 사용 통계·진단 데이터 | 사용 패턴 분석을 통한 서비스 개선·크래시 진단 |

회사는 위 목적 외의 용도로 개인정보를 이용하지 않으며, 이용 목적이 변경될 경우 별도의 동의를 받습니다. 이용자 데이터를 광고 타겟팅·판매·외부 공개 목적으로 이용하지 않습니다.

## 6. 이용자의 권리

이용자는 언제든지 다음 권리를 행사할 수 있습니다.

- **열람** — 앱 내 본인이 작성한 모든 콘텐츠·참가 기록 확인 가능
- **정정** — 앱 내 편집 기능으로 직접 수정 (프로필, 클럽 설정, 대회 정보)
- **삭제** — 개별 콘텐츠 삭제, 또는 MY 탭의 "계정 삭제"로 일괄 삭제. 자세한 절차는 [계정 삭제 안내](delete.html) 참고
- **처리 정지·반대** — {{LEGAL_EMAIL}} 으로 요청
- **이동권 (데이터 내보내기)** — {{LEGAL_EMAIL}} 으로 요청 시 JSON 형식으로 30일 이내 제공
- **동의 철회** — 동의 기반 처리(푸시 알림 등)는 OS 설정 또는 앱 내에서 언제든 철회

권리 행사는 이용자 본인이 직접, 또는 법정대리인을 통해 가능하며, 회사는 30일 이내에 처리합니다. 권리 행사 결과에 이의가 있는 경우 개인정보 보호위원회 등 거주 지역의 감독 기관에 불복 신고가 가능합니다.

### 캘리포니아 거주자 (CCPA/CPRA)
캘리포니아 거주자는 개인정보의 알 권리, 삭제권, 정정권, 민감 개인정보 이용 제한권을 추가로 가집니다. 회사는 행동 광고 목적으로 개인정보를 판매하거나 공유하지 않습니다.

### EEA / UK / 스위스 거주자 (GDPR)
GDPR 제6조에 따른 처리의 적법 근거는 다음과 같습니다:
- **계약 이행** — 이용자가 가입한 서비스의 제공 (Article 6(1)(b))
- **정당한 이익** — 서비스 보안, 오류 진단, 기능 개선 (Article 6(1)(f)). 언제든 이의 가능
- **동의** — 푸시 알림 등 법령상 동의가 필요한 처리. 언제든 철회 가능
- **법적 의무** — 법령상 의무 이행
